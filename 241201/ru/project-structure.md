## Структура проекта

** todo требует изменений

В основном в любой проект входят ассеты (заготовленные материалы) по типу моделей, изображений, звуков и вообще много чего ещё под конкретную задачу проекта. А вторая часть это код, логика работы и взаимодействия.

Чтобы создать новый проект, вы можете использовать встроенный менеджер пакетов RTS со следующими командами:

* `./rts package local`
* `./rts package local <package name>`

Для более подробной информации о командах вы можете использовать:

* `./rts package help`
